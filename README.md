# Machu Pachu

Family app + server to send photos, kids' drawings and text to a 7" Waveshare PhotoPainter (ESP32-S3, 800×480, 6-color e-paper).

- `server/`: Python image-processing and API server
- `app/`: Android app (camera-first)
- `docs/requirements.md`: functional requirements
- `docs/tasks.md`: task list
- `docs/status.md`: what's done and what's next
